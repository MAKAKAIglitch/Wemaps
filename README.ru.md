# Wemaps

**Независимый открытый Android-проект карты и навигации на основе OpenStreetMap и MapLibre Native.**

Wemaps разрабатывается как Android-приложение, в котором карта — главный экран. При запуске сразу открывается подробная перспективная карта с объёмными зданиями, читаемой геометрией дорог и собственным картографическим стилем.

> **Статус:** в репозитории уже есть минимальная основа Android-приложения с картой и слоем 3D-зданий. Поиск, маршрутизация, слежение за GPS, предупреждения о камерах, погода и подробная полосная навигация остаются следующими этапами разработки.

## Направление проекта

- Полноэкранная карта сразу после запуска.
- Перспективная 3D-камера по умолчанию.
- Объёмные здания там, где исходные данные позволяют их построить.
- Собственный редактируемый тёмный стиль **Midnight Navigation**.
- Сохранённый альтернативный пресет **Violet Night**.
- Ширина дорог и структура полос по доступным картографическим атрибутам.
- Читаемая геометрия полос и подсветка подходящих маршруту полос на следующих этапах.
- Камеры контроля скорости с сохранением координат и направления из источника; загрузка камер не должна задерживать отрисовку дорог.
- Отсутствие собственных серверов Wemaps на первом этапе разработки.

## Технологическая основа Android

| Область | Технология |
|---|---|
| Платформа | Android |
| Язык | Kotlin |
| Интерфейс | Jetpack Compose + Material 3 |
| Движок карты | MapLibre Native Android (Vulkan с OpenGL ES fallback) |
| Геоданные | Векторные данные на основе OpenStreetMap |
| Первоначальный поставщик карты | OpenFreeMap |
| Объёмные здания | Слой MapLibre fill-extrusion |
| Настройки и будущий кэш | Локальное хранилище Android / Room при необходимости |

Прототип использует публичный тёмный стиль OpenFreeMap как заменяемый источник. Приложение добавляет собственный слой 3D-зданий и применяет собственные цветовые токены к поддерживаемым слоям карты.

## Дизайн карты

Начальный пресет — **Midnight Navigation**: тёмная сине-серая основа, различимая иерархия дорожного покрытия и контрастный маршрут. Это собственные значения цветов Wemaps, а не скопированные брендовые ресурсы.

Все цветовые токены вынесены в [design/map-style-presets.json](design/map-style-presets.json). Там предусмотрены два пресета:

- `midnight-navigation` — основной тёмный стиль.
- `violet-night` — альтернативная фиолетовая палитра.

В дальнейшем можно добавлять стили и пользовательские переопределения цветов без переписывания логики отрисовки.

## Геометрия дорог и полосы

Карта должна использовать наиболее точные доступные данные OSM:

- `width=*` — указанная физическая ширина;
- `est_width=*` — оценочная ширина;
- `lanes=*`, число полос по направлениям и `width:lanes=*` — структура полос;
- `turn:lanes=*` — направление движения по отдельным полосам;
- `lane_markings=*` и `road_marking=*`, если они присутствуют.

Измеренные значения, оценки и стилистические значения по умолчанию должны храниться отдельно. Если точная геометрия полос или разметки отсутствует, автоматически построенные линии считаются схематичными, а не фактически измеренной дорожной разметкой.

Поставщик векторных тайлов должен передавать необходимые атрибуты. Подготовка дополнительных данных о дорогах и камерах не должна блокировать основную карту.

Подробнее: [спецификация дорог и камер](docs/ROAD_RENDERING.md).

## Сборка

Требования:

- JDK 17.
- Android SDK с платформой API 36 и Android Build Tools 36.0.0.
- Интернет для первой загрузки Gradle и зависимостей.

Linux / macOS:

```bash
./gradlew :app:assembleDebug
```

Windows:

```bat
gradlew.bat :app:assembleDebug
```

Проектный скрипт запуска загружает закреплённую версию Gradle и проверяет её SHA-256 перед запуском. Репозиторий также можно открыть как Gradle-проект в Android Studio.

Пока поддержка местоположения устройства не реализована, камера карты открывается в нейтральной демонстрационной области. Первая версия не запрашивает разрешение на геолокацию.
