# Independent implementation and project identity

Wemaps is an independent open-source Android project built around OpenStreetMap data and MapLibre Native.

## Implementation principles

- Write application code specifically for this repository.
- Design the app's own information architecture, screen layouts, map styling, icons, illustrations, sounds, and animations.
- Use public standards, published documentation, open datasets, and independently authored technical requirements.
- Do not copy, extract, decompile, or adapt proprietary source code, private APIs, internal SDKs, logos, screenshots, audio, artwork, or other protected assets from third-party products.
- Do not imitate a third-party product's exact screen composition, distinctive iconography, typography, branded color system, or other identifying visual expression.
- Keep all external libraries, map data, styles, fonts, and service providers separately identified with their own licenses and attribution requirements.
- Keep the Wemaps name and logo distinct from third-party product names and marks.

## Public project description

Describe Wemaps as an independent, OpenStreetMap-based Android map and navigation project. Do not describe it as an official edition, clone, fork, partner, or endorsed version of another navigation product.

Wemaps is not affiliated with or endorsed by third-party navigation providers. Names and marks of external projects remain the property of their respective owners.

## OpenStreetMap and MapLibre

OpenStreetMap is a public geographic database, not a ready-made visual design. Its data is used under the Open Database License (ODbL) and must be attributed according to the applicable requirements.

MapLibre Native is an independent open-source renderer. Its source code and binary dependencies retain their own license terms. The selected tile provider's style, tiles, caching rules, attribution, and service terms must also be reviewed.

## What this policy does and does not mean

This policy defines the project's engineering and branding discipline. It is not a legal certification, does not guarantee that a platform will never moderate a listing or repository, and does not replace qualified legal advice where that is needed.

A feature being common in navigation software does not give permission to copy a particular implementation, visual asset, private API, or protected design expression. When in doubt, implement the behaviour from public requirements and original design work, and document the data source and technical rationale.
